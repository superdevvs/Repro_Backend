# Isolated automatic staging candidate

This candidate is disabled by default and is not deployed or advertised as ready.
The first supported scope is an empty living room with exactly one sofa, one coffee
table and one accent chair. A rug, extra objects, occupied rooms, ambiguous context,
or unresolved reflections/occlusion stop at `needs_review`. No automatic image
repair or operator acceptance is added.

The persisted workflow reserves three analysis steps (original source plan, actual
section plan, typed actual-placement assessment), one image, two segmentation
steps, and one visual evaluation. The source-floor receipt must pass before the
candidate-furniture request is eligible. A stored step UUID is the only child
request identity. Existing cancellation and ambiguous-submission holds apply.

An imported native panorama is verified against the completed creating import.
The first plan proposes one section. Generation uses the actual extracted source
bytes and a new section-bound analysis with verified original parent context;
uploaded-attachment authority is never fabricated. Mask order does not identify
objects. The typed assessment, provider receipt, raw response, exact mask bytes,
decoded bounds, source/candidate hashes and geometry are revalidated on reuse.

The pinned support worker refines machine coverage and derives bounded floor
contact support. Native composition projects generated RGB only through object
alpha and applies scalar shadows directly to the original floor. Seven matched
full-sphere boards feed the independent evaluator. Evaluation retains original
user instructions, separately bound fixed recipe constraints, and original-source
as well as section protections/caveats. Oversized context stops instead of dropping
constraints. Numeric preservation does not prove semantic quality.

Composite lineage retains the exact server extraction `editView` and geometry
digest for a future additive viewer-focus DTO. These are extraction coordinates,
not calibrated physical camera measurements. Native export dimensions are not
native generated detail, and the scope remains one panorama.

The private imported-source integration uses synthetic imagery and intercepted
provider responses, with real extraction, support, composition and evidence
workers. It proves mechanics only. A separate 11008×5504 synthetic resource proof
exercises the compositor and evidence worker under 3 GiB address-space / 220 CPU
second limits, exact replay and changed-input rejection. Neither proof establishes
fresh unattended real-scene quality or authorizes live provider execution.
