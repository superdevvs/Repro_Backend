# Bounded Interior material candidate

This experimental recipe restyles 2–5 complete existing opaque matte furnishing surfaces through visible textile, texture or pattern guidance. It preserves the original forms, layout, large folds, contacts and protected foreground. It does not implement new furniture, layout changes, hidden receiver reconstruction, glass, glossy materials or general room redesign. All five existing style names are accepted as requested intent; support and recognizable style success must be established for the actual source and final candidate. A palette-only result cannot become ready.

The capability is disabled by default. Synthetic tests demonstrate orchestration and numerical invariants, not successful style rendering on real rooms. No real provider calls or live activation are part of this candidate's validation.

## Durable sequence

1. A typed original-panorama assessment may nominate an exact source framing. It cannot authorize image generation.
2. The server extracts that section for free. A separate typed assessment sees the authoritative cut and verified original panorama context, and must pass scope, optics, foreground, contact and style checks.
3. Source-only machine segmentation identifies complete material regions and any protected foreground. A numerical source-support operation verifies topology, margins, unoccluded area and measurable structure before an image is reserved.
4. One image uses the exact typed cut prompt and prepared source. A dedicated source-machine-plan snapshot binds the assessment, source preparation and persisted source-support report. Authority is revalidated on each primary or explicit quota fallback attempt.
5. A typed actual-candidate assessment must pass geometry, material and style checks before candidate masks are requested. No returned mask order is treated as semantic identity.
6. Measured donor-to-source registration, held-out residuals, coverage and non-colour detail determine whether a bounded material field can be applied to native source pixels. There is no identity-registration fallback. Original pixels outside effective alpha remain exact.
7. Full-sphere source/candidate boards and an exact section detail go to the independent quality evaluator with the original user style intent and explicit material constraints. Numeric success or a planner's style claim is not acceptance.

The fixed budget is three typed analyses, one image, at most fifteen SAM calls (up to five source materials, five source foreground objects and five candidate materials), one section, one composition and one independent evaluation. It has no automatic repair. Unknown submissions are held; queued-only recovery preserves the original UUID. Completed receipts, masks and local outputs are revalidated on replay.

## Runtime and private contracts

`IGUIDE_LAB_INTERIOR_DESIGN_WORKFLOW_ENABLED` defaults to false. The assessment and material manifests and material interpreter path default to null. The material adapter checks exact code hashes, interpreter path and executable hash and performs a real pinned-runtime probe before spend. The Python worker pins Python 3.12.3, NumPy 2.5.4, Pillow 13.0.0 and OpenCV 5.0.0, with 3 GiB address space, 180 CPU seconds and a 200-second caller timeout. Measured Linux resource evidence is required before rollout; these limits alone do not prove readiness.

Typed records have no public write route. Public callers cannot supply the internal prompt mode, machine plan, reviewed masks or approval assertions. A new automatic run has `sourceMachinePlan.version = machine-interior-material-plan/1`; it is distinct from successful scene analysis provenance. Frontend strict read compatibility must be reviewed using actual completed-chain DTOs before any activation.

The material worker returns only `unreviewed` or `needs_review`. The source-only operation returns `eligible_for_donor_request` or `needs_review` and explicitly grants no image or transfer authority by itself. Final workflow Ready means the bounded automated checks passed; it never means human acceptance or independent cross-view verification.

## Evidence limits

Historical successful style examples used manual supports, contour repairs, source reconstruction or guided detail registration. Those masks are not machine authority for this recipe. The retained B05 modern material experiment was unaccepted and is failure/calibration evidence only. Registration does not establish textile semantics, pattern perspective, material realism or recognizable style; independent real-scene evaluation remains necessary.
